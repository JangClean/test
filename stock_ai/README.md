# 주식 매수/매도 AI 모델

LightGBM으로 "N거래일 뒤 주가가 오를 확률"을 예측하고, 그 확률로 매수/매도 신호를 내는 모델입니다.

## 구조
| 파일 | 역할 |
|---|---|
| `data.py` | yfinance로 일봉 다운로드 + `data_cache/`에 캐시 |
| `features.py` | 수익률, 이동평균 괴리율, RSI, MACD, 볼린저밴드, 변동성, 거래량, 52주 고저, 시장지수 대비 강도 등 피처와 라벨 |
| `model.py` | LightGBM 분류기, 워크포워드 학습(과거로만 학습 → 다음 구간 예측 반복) |
| `backtest.py` | 확률 → 포지션 변환, 거래비용 반영 백테스트, 성과지표 |
| `main.py` | 실행 스크립트 |

## 사용법
```bash
pip install -r requirements.txt

python main.py backtest 005930.KS            # 삼성전자 백테스트 (output/에 CSV와 차트 저장)
python main.py backtest 000660.KS AAPL NVDA  # 여러 종목
python main.py predict 005930.KS             # 최신 종가 기준 매수/매도/관망 신호
```
티커 형식: 코스피 `005930.KS`, 코스닥 `035720.KQ`, 미국 `AAPL`.

주요 옵션: `--horizon 5`(예측 기간), `--buy-th 0.55` / `--sell-th 0.45`(매수·매도 확률 기준),
`--cost 0.0015`(매매 1회 비용), `--retrain-every 63`(재학습 주기), `--no-market`(시장지수 피처 끄기).

## 누출 방지 설계
- 피처는 당일 종가까지만 사용하고, 신호는 **다음 날 시가에 체결**한다고 가정합니다.
- 워크포워드 학습 시 학습 구간 끝 `horizon`일을 잘라내 라벨이 미래 가격을 엿보지 않게 했습니다.
- 매매마다 수수료·세금·슬리피지(`--cost`)를 차감합니다.

## 주의
투자 판단 참고용 학습 프로젝트입니다. 기본 설정의 백테스트 성과는 단순 보유보다 낮을 수 있으며,
백테스트 성과가 실전 수익을 보장하지 않습니다.
